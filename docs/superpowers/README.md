# Documents de conception

Ce dossier garde la trace des décisions, pas l'état du produit.

Les **specs** ont été écrites avant chaque chantier, les **plans** pour
l'exécuter. Les uns et les autres sont datés et ne sont **pas tenus à jour** :
plusieurs annoncent un numéro de schéma dépassé, et le plus ancien plan nomme
une bibliothèque de placement qui a été remplacée depuis.

On les garde parce qu'ils expliquent *pourquoi* les choses sont ainsi — ce
qu'un code, même bien commenté, dit mal. Pour savoir *comment* elles sont, lire
le code, ou le README à la racine.
